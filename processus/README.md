# Processus

Ce dossier explique comment l’équipe et les agents IA travaillent sur Chaye.

## Document principal

Le workflow complet est regroupé dans :

```text
processus/workflow-agentique.md
```

Ce document couvre :

- l’utilisation de GitHub CLI `gh` ;
- la création et le cadrage des issues ;
- la granularité des tickets agentiques ;
- la séparation entre PR feature, `docs-sync` et `OPS` ;
- la validation Docker-first ;
- la définition de fini.

## Public concerné

- nouveaux développeurs ;
- reviewers ;
- responsables produit ;
- agents IA ;
- toute personne qui crée ou suit des issues GitHub.

## Mise à jour

Mettre à jour ce dossier lorsqu’une règle d’équipe, un quality gate, une convention GitHub ou une règle agentique change.
