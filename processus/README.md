# Processus

Ce dossier explique comment l'equipe travaille.

Il doit etre lu par:

- les nouveaux devs;
- les reviewers;
- les agents IA;
- toute personne qui cree ou suit des issues GitHub.

Il sert a cadrer:

- l'onboarding;
- le processus GitHub issues;
- le processus pull request;
- la Definition of Done;
- le travail agentique.

Mettre a jour ce dossier quand:

- le processus d'equipe change;
- un nouveau quality gate devient obligatoire;
- la facon d'utiliser les issues GitHub change;
- une regle agentique est ajoutee.
